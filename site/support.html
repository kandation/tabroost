Support

Contact, bug reports and ideas: open an issue on the project's GitHub page (https://github.com/kandation/tabroost/issues). Please do not post private data there.

How do I export my data?

Open the saved list (click the toolbar icon, or press Alt+Shift+O), then use Export (Settings, Export / import). Save the file somewhere safe. To bring it back use Import and choose the file.

I installed from the store and my old tabs are gone

The store version has a different extension ID than a copy loaded from a folder, so data does not carry over. Open the old copy, export, then import in the new one.

Why does it ask for access to all websites?

Only for a short check before a tab is put to sleep: does the page have unsaved typing or playing media? Nothing is read, stored or sent.

What is the "Tabroost sync data" bookmark folder?

It exists only if you turned on sync. It holds encrypted data in bookmarks pointing to https://cmr.invalid/ (a reserved address that never opens). Do not edit it. Turn off sync in Settings to remove it.

I forgot my sync passphrase

It cannot be recovered. Turn off sync, delete the folder, and set up sync again; your local list on each device is unaffected.

A tab I was typing in was put to sleep

Add that site to the protected list in Settings, and tell us which site so we can improve the check.

How do I report a bug?

Open an issue with your Tabroost version, Chrome version and steps to reproduce. Please do not include private URLs.

ช่วยเหลือ

ติดต่อ แจ้งบั๊ก หรือเสนอความคิด ได้โดยเปิด issue ที่หน้า GitHub ของโครงการ (https://github.com/kandation/tabroost/issues) โปรดอย่าโพสต์ข้อมูลส่วนตัวที่นั่น

ส่งออกข้อมูลอย่างไร

เปิดรายการที่เก็บไว้ (กดไอคอนบนแถบเครื่องมือ หรือกด Alt+Shift+O) แล้วใช้ ส่งออก (การตั้งค่า, ส่งออกและนำเข้า) บันทึกไฟล์ไว้ในที่ปลอดภัย จะนำกลับมาให้ใช้ นำเข้า แล้วเลือกไฟล์

ติดตั้งจากสโตร์แล้วแท็บเก่าหาย

ส่วนขยายจากสโตร์มี ID ต่างจากชุดที่โหลดจากโฟลเดอร์ ข้อมูลจึงไม่ย้ายตามกัน เปิดชุดเก่า ส่งออก แล้วนำเข้าในชุดใหม่

ทำไมขอเข้าถึงทุกเว็บไซต์

ใช้ตรวจสั้น ๆ ก่อนพักแท็บเท่านั้น ว่าหน้านั้นมีข้อมูลที่พิมพ์ค้างหรือกำลังเล่นสื่อหรือไม่ ไม่อ่าน ไม่เก็บ ไม่ส่งอะไร

โฟลเดอร์บุ๊กมาร์ก "Tabroost sync data" คืออะไร

มีเฉพาะเมื่อคุณเปิดซิงค์ เก็บข้อมูลที่เข้ารหัสในบุ๊กมาร์กที่ชี้ไป https://cmr.invalid/ (ที่อยู่สงวนที่เปิดไม่ได้) อย่าแก้ไข ปิดซิงค์ในการตั้งค่าเพื่อลบโฟลเดอร์

ลืมรหัสผ่านซิงค์

กู้คืนไม่ได้ ให้ปิดซิงค์ ลบโฟลเดอร์ แล้วตั้งซิงค์ใหม่ รายการในแต่ละเครื่องไม่ได้รับผลกระทบ

แท็บที่กำลังพิมพ์ถูกพัก

เพิ่มเว็บไซต์นั้นในรายการที่กันไว้ในการตั้งค่า และแจ้งชื่อเว็บไซต์มาเพื่อให้เราปรับการตรวจ

แจ้งบั๊กอย่างไร

เปิด issue พร้อมรุ่นของ Tabroost รุ่นของ Chrome และขั้นตอนที่ทำให้เกิดซ้ำ โปรดอย่าใส่ URL ส่วนตัว
