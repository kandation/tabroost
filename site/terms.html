Effective date: 2026-11-24

As is

Tabroost is free software released under the MIT License. It is provided "as is", without warranty of any kind. To the extent the law allows, the developer is not liable for loss of data or any other damage from using it.

Your data is local

Saved tabs, settings and statistics live in your browser on your device. If you remove the extension, clear browser data, or the profile is damaged, they can be lost. You are responsible for your backups: use Export in the list page regularly. The Chrome Web Store version has a different extension ID than a copy loaded from a folder, so data does not carry over between them; export first and import after.

Sleeping and closing tabs

Tabroost closes tabs when you save them and puts idle tabs to sleep when you enable auto-sleep. It tries to skip tabs with unsaved input or playing media, but it cannot detect everything (for example unsaved work inside some web apps). Add important sites to the protected list.

Sync and encryption

Optional sync encrypts data with a passphrase you choose. If you forget the passphrase the synced data cannot be recovered. The local list is not encrypted by Tabroost (see the privacy policy). Do not edit or delete the sync bookmark folder while sync is on. Sync depends on your browser's own bookmark sync and its availability.

Password lock

If you turn on the optional password lock, a forgotten password cannot be recovered by the developer, and you may lose access to the locked list unless you have the recovery key, a backup password or passkey you set up, or an encrypted backup file (.tabroost) made before you erase. The lock works together with sync: synced data stays encrypted with the sync passphrase and the lock key protects the data on this computer.

Acceptable use

Use Tabroost lawfully. Do not use it to break the rules of websites you visit.

Changes and contact

These terms may change; the current version is on this page. Questions: open an issue on the project's GitHub page (Issues). Please do not post private data there.

ข้อมูลอยู่ในเครื่อง

แท็บที่เก็บไว้ การตั้งค่า และสถิติ อยู่ในเบราว์เซอร์บนเครื่องของคุณ ถ้าถอนส่วนขยาย ล้างข้อมูลเบราว์เซอร์ หรือโปรไฟล์เสียหาย ข้อมูลอาจหายได้ คุณรับผิดชอบการสำรองข้อมูลเอง โปรดส่งออกจากหน้ารายการเป็นประจำ ส่วนขยายจาก Chrome Web Store มี ID ต่างจากชุดที่โหลดจากโฟลเดอร์ ข้อมูลจึงไม่ย้ายตามกัน ให้ส่งออกก่อนแล้วนำเข้าทีหลัง

การพักและปิดแท็บ

Tabroost ปิดแท็บเมื่อคุณเก็บ และพักแท็บที่ไม่ได้ใช้เมื่อคุณเปิดการพักอัตโนมัติ โดยพยายามข้ามแท็บที่มีข้อมูลยังไม่บันทึกหรือกำลังเล่นสื่อ แต่ตรวจได้ไม่ทุกกรณี (เช่น งานที่ยังไม่บันทึกในเว็บแอปบางตัว) ควรเพิ่มเว็บไซต์สำคัญในรายการที่กันไว้

ซิงค์และการเข้ารหัส

การซิงค์ที่เป็นตัวเลือกเข้ารหัสข้อมูลด้วยรหัสผ่านที่คุณตั้ง ถ้าลืมรหัสผ่าน ข้อมูลที่ซิงค์จะกู้ไม่ได้ รายการในเครื่อง Tabroost ไม่ได้เข้ารหัส (ดูนโยบายความเป็นส่วนตัว) อย่าแก้หรือลบโฟลเดอร์บุ๊กมาร์กซิงค์ขณะเปิดซิงค์ การซิงค์ขึ้นกับการซิงค์บุ๊กมาร์กของเบราว์เซอร์และความพร้อมของบริการนั้น

ล็อกด้วยรหัสผ่าน

ถ้าคุณเปิดล็อกด้วยรหัสผ่าน (ตัวเลือก) ผู้พัฒนากู้รหัสผ่านที่ลืมให้ไม่ได้ และคุณอาจเข้ารายการที่ล็อกไม่ได้ ถ้าไม่มีรหัสกู้คืน รหัสผ่านสำรอง พาสคีย์ หรือไฟล์สำรองที่เข้ารหัส (.tabroost) ที่ทำไว้ก่อนลบ ล็อกใช้ร่วมกับซิงค์ได้ ข้อมูลที่ซิงค์ยังเข้ารหัสด้วยรหัสผ่านซิงค์ และกุญแจของล็อกปกป้องข้อมูลในเครื่องนี้
